# Dhruv Savaj — Portfolio

A single-page personal portfolio built with **plain HTML and CSS** plus ~80 lines of
vanilla JavaScript. No framework, no build step, no npm — the files you see are the
files that get served.

## Structure

```
index.html                       the whole page
css/style.css                    design tokens + all layout
js/script.js                     mobile nav, active-link highlight, scroll reveal
assets/favicon.svg               "DS" monogram
.nojekyll                        tells GitHub Pages to serve files as-is
```
